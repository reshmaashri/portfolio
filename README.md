## 🎨 Design System & Aesthetics
- **Bespoke Editorial Architecture:**
  - **Balanced Soft Slate / Alabaster Light Theme (Default):** Soft porcelain mist `#F8FAFC`, crisp white cards `#FFFFFF`, refined borders `#E2E8F0`, deep slate ink text `#0F172A` & `#1E293B`.
  - **Royal Indigo & Violet Accents:** `#4361EE` & `#7209B7`, replacing generic blue/cyan glows.
  - **Status Indicators:** Vibrant emerald green `#10B981` indicating active availability and verified live deployments.
  - **Integrated Dark Theme Support:** Sleek midnight obsidian theme toggle (`data-theme="dark"` / `localStorage` persistence).
- **Interactive Developer Console:**
  - Bespoke macOS terminal code window featuring tabbed inspection (`developer.ts` and `cloud-status.sh`), live pulse status, and repository links.
- **Typography:**
  - Headings & Body: `Plus Jakarta Sans` (Google Fonts)
  - Code, Metrics & Badges: `JetBrains Mono`
- **User Experience Highlights:**
  - Clean, human-crafted developer aesthetic tailored to impress corporate recruiters and tech leaders
  - Fully responsive across desktop, tablet, and mobile devices (down to 320px) with non-overlapping flex layouts
  - Smooth scrolling with offset compensation for the fixed glassmorphic navigation bar
  - Interactive project filtering by domain (`All`, `Cloud & HPC`, `AI & ML`, `IoT & Sensors`, `Web & Graphics`)
  - Accessible project deep-dive modals detailing system architecture and mathematical foundations
  - One-click copy email button with interactive toast confirmation
  - Direct PDF resume download button
