## 🌐 Deployment Instructions

### Deploy to GitHub Pages (Free & Permanent)
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit for InAmigos Task 1"
   ```
2. Create a new GitHub repository named `portfolio` or `reshmaashri.github.io`.
3. Add remote and push:
   ```bash
   git branch -M main
   git remote add origin https://github.com/reshmaashri/portfolio.git
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings > Pages**, select the `main` branch, and save.
5. Your live URL will be: `https://reshmaashri.github.io/portfolio/`.

### Deploy to Netlify / Vercel (Drag-and-Drop)
1. Go to [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com).
2. Drag and drop the `InAmigos_Foundation_Task_1` folder directly into the browser.
3. Your website will be instantly live on a public URL.
