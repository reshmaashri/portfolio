GPU-Based Image Processing (Sobel Edge Detection)

High Performance Computing GPU Parallelism Sobel Filter AWS EC2 Cloud

Overview

A High Performance Computing implementation engineered to offload computationally intensive 2D image convolution and gradient filtering onto GPU parallel architectures.

Technical Architecture & Acceleration

  • Parallel Kernel Execution: Executes simultaneous discrete spatial convolutions across pixel blocks using horizontal and vertical Sobel differential operators ($G_x$ and $G_y$).
  • Gradient Magnitude & Thresholding: Computes $|\nabla I| = \sqrt{G_x^2 + G_y^2}$ simultaneously with GPU thread blocks, yielding substantial speedups over sequential CPU implementations.
  • Live AWS Cloud Microservice: Hosted on an Amazon Web Services (AWS) EC2 virtual machine, exposing a real-time web interface for test image uploads and live edge extraction.

Satellite Image Classification (Deep Learning & MRF)

Deep Learning Markov Random Field Satellite Vision Google Colab

Mathematical & Neural Framework

An advanced terrain classification system integrating deep neural feature extraction with probabilistic Markov Random Fields (MRF) to eliminate pixel-level noise and ensure territorial spatial continuity in multispectral satellite imagery.

Methodology & Research Contributions

  • Deep Feature Representation: Extracts high-level contextual spectral representations from multi-band satellite data using convolutional neural networks.
  • Markov Random Field (MRF) Spatial Modeling: Formulates class assignment as a Maximum A Posteriori (MAP) energy minimization problem over pairwise clique potentials, penalizing isolated misclassified pixels.
  • Iterative Energy Optimization: Applies probabilistic inference (Iterated Conditional Modes / Gibbs sampling) to produce clean, sharp terrain and vegetation boundaries.

Interactive Notebook: Google Colab Research Notebook (Untitled10.ipynb)

Focus: Mathematics, Deep Learning & Remote Sensing
